Build, run and map LISFLOOD-FP flood inundation models without leaving QGIS. This two-minute walkthrough of the open-source LISFLOOD-FP for QGIS plugin goes from ordinary map layers to an animated flood.

There's no narration. On-screen captions explain each step.

What you'll see
• The inputs are ordinary QGIS layers: a DEM, an inflow point and its hydrograph.
• Point the plugin at the LISFLOOD-FP source code once, and it compiles the model for you.
• Set up the model in the plugin's panel. You choose the DEM and Manning's n, add a point inflow with a hydrograph in m³/s (the plugin converts it to the per-metre discharge LISFLOOD-FP expects), and add an automatic outflow boundary.
• Build and run six hours of model time. The model runs in the background, and the panel shows a live mass balance: wetted area, volume, and flow in and out.
• The results load as styled, georeferenced layers: maximum depth, depth through time, time of first inundation and more. The QGIS Temporal Controller steps through the flood.
• Every step is also a Processing tool, so you can use it in graphical models, batch runs and qgis_process.

The valley in this video is synthetic, made for the demonstration. It's a 4.8 × 3.2 km, 10 m DEM with a meandering river and a village of 148 buildings, and the flood hydrograph peaks at 250 m³/s.

Get the plugin
In QGIS, go to Plugins ▸ Manage and Install Plugins and search for "QGIS-LISFLOOD-FP".
Plugin page: https://plugins.qgis.org/plugins/lisflood_fp/
Code and issue tracker: https://github.com/simreaney/QGIS-LISFLOOD-FP
The plugin needs QGIS 3.28 or later and works in QGIS 4. This video was filmed in a QGIS 4.3 development build.

LISFLOOD-FP itself is not bundled with the plugin. Download the LISFLOOD-FP v8.2 source code from Zenodo (GPL-2.0), and the plugin builds it for you: https://doi.org/10.5281/zenodo.13121102
